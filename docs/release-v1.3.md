## 新增
- 增加图形化界面，支持指定 GitHub 用户选择仓库，或直接扫描单个仓库。
- 增加实时进度、结果筛选、运行日志，以及 JSON / CSV / TXT 报告导出。
- 提供 Windows x64 单文件 EXE，无需安装 Python。

## 优化
- 优化并发扫描、重复文件去重和目录树缓存，减少重复请求。
- 优化取消响应、异常提示、限流处理和高 DPI 显示。
- 修复同一行多厂商配置的识别归属和重复路径源码链接问题。
- 优化敏感信息脱敏和部分扫描报告，保留覆盖统计与任务状态。

## 使用说明
- 下载 `APIKeyLeak.exe` 后双击运行；`APIKeyLeak.exe.sha256` 用于校验文件。
- 新 GUI 用于自有或已授权仓库自查，只进行离线特征识别，不验证发现的密钥、不查询余额。
- EXE 未签名；源码与旧命令行入口保留。验证记录和构建方式见仓库 README。
