## 独立代码审查及修复复核

首次只读审查指出文件名元数据泄漏、异常文本泄漏、密集识别取消延迟及截断目录树请求放大四项重要问题，均已新增测试并修复：

- 结果对象、日志及列表的敏感元数据保守脱敏；元数据被脱敏时禁用直达源码链接，所有报告不保留完整匹配密钥。
- GitHub 元数据进行受控类型校验；后台不显示任意 `ValueError` 文本。
- 检测使用排序后线性包含判断，并在每行后让出事件循环；独立复核的原始约 1 MB 密集样本取消耗时为 0.093 秒，原问题为 4.93 秒。
- 忽略目录在遍历前剪枝，树响应按 SHA 缓存；独立复核中 200 个重复可扫描子树仅需 4 次元数据请求，并保留全部 200 个路径位置。
- JSON/CSV/TXT 报告保留运行、取消、失败、部分完成状态及覆盖计数和大小/并发配置。

第一次独立复核确认原四项问题关闭。第二次复核发现以下边界问题，均已补充回归测试并修复：

- 同一行含多个厂商配置时，只用当前赋值变量名判断厂商，避免继承前一个配置项的名称；覆盖 JSON 和分号分隔配置。
- 相同 blob 展开多个路径时，每条路径及每 250 条结果让出事件循环，取消不再等待整个展开完成。
- 检测结果不再绑定首个路径，避免敏感文件名使同一 blob 下的正常文件链接也被禁用。

上述回归测试使用本地合成夹具，不调用真实密钥。

第二次独立复核确认三项问题关闭：原始多厂商样本识别正确，重复路径取消在首批后停止，正常文件链接在两种路径顺序下均保留；完整 56 项测试复跑通过。
